# school2game

_Учись с игровым вайбом._

Игра для телефона на скорость для 5 класса. Предметы: математика (умножение, деление) и русский язык (словарные слова, ударения, -тся/-ться). Футбол и баскетбол, форматы 1×1 и 2×2, три уровня, соперники-боты. Игра запоминает ошибки по темам, подсказывает, что хромает, и умеет тренировать слабые места.

Подробный план и принятые решения: [docs/plan.md](docs/plan.md).

## Структура

| Путь | Что это |
|---|---|
| `www/index.html` | вся игра в одном файле (HTML, CSS, JS) |
| `www/fonts/` | шрифты Russo One и Neucha, чтобы игра работала без интернета |
| `capacitor.config.json` | настройки Android-обёртки (Capacitor 7) |
| `android/` | Android-проект, из него собирается APK |
| `.github/workflows/android-apk.yml` | сборка APK в GitHub Actions |
| `tools/make-icons.py` | генератор иконок приложения |
| `docs/artifact-version.html` | версия игры с подключением шрифтов из Google Fonts, как она опубликована в Claude |

## Запуск в браузере

Откройте `www/index.html` в браузере или отдайте папку `www` любым веб-сервером. Для автодеплоя на свой сервер достаточно копировать содержимое `www`.

## Сборка APK

**Через GitHub Actions.** После каждого пуша в `main` (или вручную: Actions, Android APK, Run workflow) собирается `app-debug.apk`. Скачайте его в разделе Artifacts запуска и установите на телефон. На телефоне нужно разрешить установку из неизвестных источников.

**Локально.** Нужны Node.js 22, JDK 21 и Android SDK (платформа 35).

```bash
npm ci
npm run apk
```

Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

## Про подпись

Отладочный APK подписывается автоматическим debug-ключом сборочной машины. У каждой новой сборки в GitHub Actions ключ другой, поэтому поверх старой версии она не встанет: сначала удалите приложение с телефона. Для постоянных обновлений и для Google Play нужен свой ключ подписи: его хранят в секретах репозитория, а собирают `assembleRelease` или `bundleRelease`.

## Настройка игры

В начале скрипта в `www/index.html` есть константы: длина матча, цель по очкам, бонус за серию, пауза после ошибки. Скорость и точность ботов по уровням лежат в объекте `LEVELS`. Банки заданий (`VOWEL`, `STRESS`, `TSYA`), генераторы и реестры `SUBJECTS` и `TOPICS` лежат между маркерами `GEN-START` и `GEN-END`: чтобы добавить тему, допишите генератор и запись в `TOPICS`.
