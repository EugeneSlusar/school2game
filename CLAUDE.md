# school2game — контекст для Claude Code

Владелец: Евгений (Саныч), IT-специалист, общаемся по-русски. Он не детский педагог, а разработчик: нужен рабочий код и короткие понятные отчёты.

## Что это
Соревновательная игра для телефона и браузера для детей 5 класса. Игроки на скорость решают задания по предметам, получают очки (футбол, баскетбол как оформление), играют против ботов. Слоган: «Учись с игровым вайбом». Раньше называлась «Табличный спорт».

Идея владельца: тренировки по всем предметам, игра определяет, какой предмет «хромает», и подтягивает его; позже кланы, которые соревнуются друг с другом, и онлайн-дуэли.

Полные решения и план: `docs/plan.md`. Передача контекста и нюансы: `docs/HANDOFF.md`. Прочитай оба файла перед работой.

## Текущий приоритет
Только веб-версия (Android на паузе). Хостинг: Timeweb Optimo (шаред), PHP + MySQL, сайт https://lab.orgbox.net/school2game/. Бэкенд (`server/`, `public_html/api/`) и клиент (аватар-кнопка вверху меню, экраны «Профиль» и «Рейтинг», смена ника и аватара, синхронизация матчей) написаны. Авторизация анонимная: игрок сразу «Неопознанный» со случайным аватаром, перенос на другое устройство по коду восстановления; внешних входов (Яндекс, Google, MAX) нет и не планируются. Ники проходят фильтр мата (`server/profanity.php`). Автодеплой настроен (GitHub Actions по SSH запускает на сервере `.deploy/sync_repo_from_git.sh --auto`; он не затирает неотслеживаемые файлы, конфликт останавливает деплой). `.env` лежит на сервере в корне, в git его нет. Онлайн-дуэли двух живых игроков (код комнаты, ссылка, случайный соперник; опрос сервера раз в секунду, отдельный рейтинг онлайн-игр) написаны: `server/duel.php`, экран «Дуэль» в клиенте. Дальше: публикация в RuStore. Подробности: `docs/plan.md`, `docs/HANDOFF.md`.

## Структура
- `docs/artifact-version.html` — ИСТОЧНИК ИСТИНЫ: вся игра в одном файле (HTML, CSS, JS), шрифты через Google Fonts.
- `public_html/index.html` — ГЕНЕРИРУЕТСЯ из источника командой `npm run build` (подставляет локальные шрифты `public_html/fonts/`). Руками не править.
- `index.html` в корне — символьная ссылка на `public_html/index.html` (сайт публикуется из корня), не править.
- `tools/make-index.js` — генератор `public_html/index.html`; `tools/gentest.js` — проверка генераторов заданий; `tools/smoke.js` — дымовой тест матча в jsdom (нужен `npm i jsdom` вне репозитория); `tools/make-icons.py` — иконки.
- `server/` — PHP-бэкенд (профили, рейтинг, фильтр ников, миграции), `public_html/api/index.php` — единственная точка входа, `tests/api.test.php` — тесты на SQLite (`npm run test:api`), `tests/profanity.test.php` — фильтр ников (`npm run test:profanity`), `tools/duel-e2e.js` — живая проверка дуэли двумя браузерами (Playwright + `php -S`, см. шапку файла), `tests/ui.test.js` — тест экранов в jsdom с поддельным сервером (`NODE_PATH=<jsdom> npm run test:ui`, как и `tools/smoke.js`). Секреты только в `.env` (в git не попадает, образец `.env.example`).
- `android/`, `capacitor.config.json` — обёртка Capacitor 7 (appId `ru.slusar.tablichnysport`, не менять, иначе APK не встанет поверх старого).
- `.github/workflows/android-apk.yml` — сборка debug APK в GitHub Actions (не проверена).

## Команды
- `npm run build` — пересобрать `public_html/index.html`.
- `npm test` — проверить банки и генераторы заданий.
- Любая правка игры: править `docs/artifact-version.html`, затем `npm run build`, `npm test`, закоммитить оба файла.

## Правила
- Тема оформления: светлая «тетрадь в клетку» и тёмная «доска»; токены цвета в `:root` + `prefers-color-scheme` + `[data-theme]`. Шрифты Russo One (заголовки) и Neucha (текст).
- Новые предметы и темы добавляются между маркерами `GEN-START` и `GEN-END` (банки, генератор, запись в `SUBJECTS` и `TOPICS`). Вопросы двух видов: `num` (ввод числа) и `choice` (выбор из вариантов).
- Пока проект на старте: все изменения сразу сливать в `main` (после тестов), без ожидания ревью. Автодеплой срабатывает на push в `main`.
- Схема БД меняется только новым файлом в `server/migrations/` (`NNN_имя.php`), старые не править. Новые миграции применяются сами при первом запросе к API.
- Коммиты на русском, в конце trailer: `Co-Authored-By` модели и ссылка на сессию, если её даёт среда.
