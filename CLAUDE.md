# school2game — контекст для Claude Code

Владелец: Евгений (Саныч), IT-специалист, общаемся по-русски. Он не детский педагог, а разработчик: нужен рабочий код и короткие понятные отчёты.

## Что это
Соревновательная игра для телефона и браузера для детей 5 класса. Игроки на скорость решают задания по предметам, получают очки (футбол, баскетбол как оформление), играют против ботов. Слоган: «Учись с игровым вайбом». Раньше называлась «Табличный спорт».

Идея владельца: тренировки по всем предметам, игра определяет, какой предмет «хромает», и подтягивает его; позже кланы, которые соревнуются друг с другом, и онлайн-дуэли.

Полные решения и план: `docs/plan.md`. Передача контекста и нюансы: `docs/HANDOFF.md`. Прочитай оба файла перед работой.

## Текущий приоритет
Только веб-версия (Android на паузе). Следующий шаг: сервер Node.js + SQLite, вход через Google (Google Identity Services, вход по аккаунту, который открыт в браузере), таблица рейтинга. Для этого нужны домен с HTTPS и OAuth Client ID от владельца (см. docs/plan.md, раздел «Веб-версия: рейтинг и вход через Google»).

## Структура
- `docs/artifact-version.html` — ИСТОЧНИК ИСТИНЫ: вся игра в одном файле (HTML, CSS, JS), шрифты через Google Fonts.
- `www/index.html` — ГЕНЕРИРУЕТСЯ из источника командой `npm run build` (подставляет локальные шрифты `www/fonts/`). Руками не править.
- `tools/make-index.js` — генератор `www/index.html`; `tools/gentest.js` — проверка генераторов заданий; `tools/smoke.js` — дымовой тест матча в jsdom (нужен `npm i jsdom` вне репозитория); `tools/make-icons.py` — иконки.
- `android/`, `capacitor.config.json` — обёртка Capacitor 7 (appId `ru.slusar.tablichnysport`, не менять, иначе APK не встанет поверх старого).
- `.github/workflows/android-apk.yml` — сборка debug APK в GitHub Actions (не проверена).

## Команды
- `npm run build` — пересобрать `www/index.html`.
- `npm test` — проверить банки и генераторы заданий.
- Любая правка игры: править `docs/artifact-version.html`, затем `npm run build`, `npm test`, закоммитить оба файла.

## Правила
- Тема оформления: светлая «тетрадь в клетку» и тёмная «доска»; токены цвета в `:root` + `prefers-color-scheme` + `[data-theme]`. Шрифты Russo One (заголовки) и Neucha (текст).
- Новые предметы и темы добавляются между маркерами `GEN-START` и `GEN-END` (банки, генератор, запись в `SUBJECTS` и `TOPICS`). Вопросы двух видов: `num` (ввод числа) и `choice` (выбор из вариантов).
- Коммиты на русском, в конце trailer: `Co-Authored-By` модели и ссылка на сессию, если её даёт среда.
