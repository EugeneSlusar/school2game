## Что сделано
- V1: меню, матч против ботов, футбол и баскетбол, форматы 1×1 и 2×2, 3 уровня, рекорды.
- V1.1: предметы и темы (математика: умножение, деление; русский: словарные слова, ударения, -тся/-ться), статистика по темам, подсказка «что хромает», режим «Слабые места», экран «Мой прогресс», разбор темы на экране результата.

## Что решил владелец (по порядку)
1. Виды спорта потом: футбол, баскетбол, бейсбол, гольф, хоккей, гонки. Форматы 1×1, 2×2, 3×3. Матч 2 минуты или набор очков.
2. Сначала боты, потом онлайн. Режима учителя не нужно.
3. Очки выбраны мной: ответ +1, быстрый +1, каждый третий подряд +3, ошибка обрывает серию, цель 50 очков на игрока. Владелец принял.
4. Roadmap-ответ: тестирование с детьми и сервер/аккаунты откладывались; предметы и диагностика сделаны.
5. Сейчас: развиваем веб-версию; добавить таблицу рейтинга и вход по аккаунту Яндекс ID (вход через Google запрещён законом 199-ФЗ).

## Правила игры (в коде: константы в начале скрипта)
`MATCH_SECONDS=120`, `POINTS_PER_PLAYER=50`, `SHOT_BONUS=3`, `FAST_SHARE=0.5`, `LOCK_SECONDS=1`. Боты: `LEVELS[...].bot` (mean, sd, min, acc). Время на вопрос: лёгкий 10 с, средний 7 с, сложный 5 с (для выбора из вариантов 12/9/7 с), хитрые примеры +1 или +3 с. Статистика: `STORE_KEY='tablichny-sport-v1'` (ключ localStorage оставлен, чтобы не терять данные). Слабая тема: точность ниже 70% на последних 30 ответах (минимум 8), «подтянуть» до 88%.

- V1.3: надёжное хранение гостя (localStorage + IndexedDB, persist), журнал матчей с `id`, резервная копия кодом, `mergeData` для переноса при входе.

## Нюансы
- Матч считается на клиенте, вопросы идут от seed (`mulberry32`), это заложено под онлайн по общему seed.
- Для рейтинга сервер должен проверять правдоподобность результата, клиенту нельзя доверять.
- Задания по русскому я составил сам: банки `VOWEL`, `STRESS`, `TSYA` (по 20–40 штук), их нужно показать учителю на проверку.
- Подпись APK: debug-ключ той машины, где собирали. Поверх ранее собранной версии новая встаёт только если ключ тот же; на другой машине (GitHub Actions) ключ другой, нужно удалить старое приложение.
- При сборке APK в песочнице Maven Central иногда отвечает 429: помогает цикл повторов и `--no-daemon --max-workers=1`. Системный `gradle` 8.14.3, JDK 21, Android SDK платформа 35.
- Версия Android сейчас: versionCode 3, versionName 1.2.
- Название «Табличный спорт» остаётся в старых ключах (`STORE_KEY`, appId) намеренно.

- V1.4 (бэкенд): PHP + MySQL на Timeweb, вход через бота MAX (вместо Яндекс ID), рейтинг, синхронизация. См. раздел «Бэкенд» в `docs/plan.md`.
- Автодеплой (`.github/workflows/deploy.yml`) падает: нет секрета `DEPLOY_SSH_KEY` и в репозитории нет `.deploy/sync_repo_from_git.sh`. Разбирать после бэкенда.
